# Running

all this in trapperai dir !

### create venv
```
python -m venv .venv
```

### activate venv
```
source .venv/bin/activate        # Linux/macOS
.venv\Scripts\activate           # Windows
```

### install packages

```
pip install -r requirements.txt
```

The requirements.txt file was typically generated by
```
pip freeze > requirements.txt
```
